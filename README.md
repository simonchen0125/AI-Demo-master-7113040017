## 1. 專案簡介

這個專案將 **人臉辨識 (InsightFace)** 與 **生成式 AI (AISuite + LLM)** 結合，做成一個互動式的 Streamlit 網頁：

1. 使用 IVE 成員照片建立人臉特徵資料庫。
2. 測試模型在測試集上的辨識準確率，並輸出統計與混淆矩陣。
3. 設計 **IVE PK 小遊戲**，讓玩家和 AI PK 誰比較會認成員臉。
4. 利用 LLM 製作 **「Lucky Vicky」正向思考文案生成器**，把生活事件轉換成 Lucky Vicky 式的幸運貼文。

## 2. 功能總覽

### 2.1 資料夾管理（Tab 1）

- 一鍵建立資料夾結構：
  - `photos/{成員英文}/`：訓練照片
  - `test_photos/{成員英文}/`：測試照片
- 支援上傳 `photos.zip / test_photos.zip` 解壓縮。
- 顯示「訓練照片概況」與「測試照片概況」（每位成員照片數與路徑）。
- 隨機抽樣顯示部分照片，快速檢查資料品質。

### 2.2 人臉特徵 & 測試（Tab 2）

- 使用 **InsightFace (buffalo_l)** 建立每位成員的平均特徵向量（face embedding）。
- 計算 `test_photos` 測試集的：
  - 每張照片辨識結果
  - 每位成員的準確率與平均信心度
- 支援：
  - 下載逐張結果 `test_results.csv`
  - 下載成員摘要 `member_summary.csv`
  - 繪製 **不同信心門檻 vs 準確率 / coverage** 曲線，協助選擇最佳門檻。
  - 顯示 **混淆矩陣 (confusion matrix)**，觀察容易被搞混的成員。
  - 用 PCA 將各成員的平均特徵降到 2D，繪製散點圖。

- 另提供「即時單張測試」：
  - 上傳一張照片，立即顯示預測成員與信心度。

### 2.3 IVE PK 小遊戲（Tab 3）

- 遊戲流程：
  1. 按「重新載入測試題庫」→ 從 `photos/{成員英文}/` 建立題庫。
  2. 按「下一題」抽一張照片，玩家選擇認為是誰。
  3. AI 同時進行辨識，雙方一起揭曉結果。
- 支援多種功能：
  - **難度模式**：
    - `Easy`：選項只給 3 個成員，且題目偏 AI 信心高的照片。
    - `Normal`：6 選 1，隨機題目。
    - `Hard`：盡量從 AI 信心較低的題目出題。
  - **錯題練習**：
    - 自動收集玩家答錯的題目。
    - 可切換成「只出錯題」模式，專門練習容易錯的人臉。
  - **提示功能**：
    - 需要提示時可請 AI 給出兩個最可能的成員與信心度。
  - **回合進度條**：
    - 顯示目前已玩回合 / 總回合數（PK 回合數可在側欄設定）。
  - **歷史紀錄 & 排行榜**：
    - 紀錄每題：正解、玩家答案、AI 答案、AI 信心度、正確與否。
    - 依玩家名稱統計作答題數、玩家正確率、AI 正確率 → 形成排行榜。

### 2.4 Lucky Vicky 生成器（Tab 4）

- 使用 AISuite 串接 LLM，產生「Lucky Vicky 式」正向思考文案。
- 提供多種風格範本：
  - IG 貼文風格
  - IG 限時動態風格
  - Line 給朋友的聊天風格
- 使用者輸入「想轉念的事件」，按下按鈕後會得到一段已轉化為幸運視角的文字，並以  
  **「完全是 Lucky Vicky 呀!」** 作結。
- 所有生成紀錄會儲存在頁面中，可下載成 `lucky_vicky_history.csv` 作為「幸運語錄本」。
